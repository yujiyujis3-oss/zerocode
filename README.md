# zerocode スターター

zerocode の学習で使う開発環境です。教材の案内に沿って、このページから自分用のコピーを作ってください。

## 使いかた

1. このページの右上にある **Use this template** から **Create a new repository** を選び、自分のコピーを作ります
2. できたコピーのページで **Code** → **Codespaces** → **Create codespace on main** を押します
3. ブラウザに編集画面とターミナルが開いたら準備完了です

くわしい手順は教材の中で、画面つきで案内しています。

## 中身

| 場所 | 説明 |
|---|---|
| `.devcontainer/` | 開発環境の設定（PHP 8.4 と Composer が入った状態で開きます） |
| `practice/` | 練習用のフォルダ。最初はここにある `index.html` を書き換えます |

このほかのファイルは、学習を進めながら自分で作っていきます。
